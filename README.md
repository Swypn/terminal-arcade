### Terminal Arcade

A collection of small terminal-based projects written in Python.

The main goal of this repository is to learn Python, become more comfortable using Linux, and have a reason to open my laptop and build something almost every day.

Most projects are intentionally kept small. If a project grows into something larger, it will likely be moved into its own repository.
Structure

arcade/
    Terminal games and experiments.

tools/
    Small utilities and scripts.

workshop/
    Assignments, practice projects, and experiments.

Current Arcade Games

    Guess Number
    Coin Flip
    Rock Paper Scissors
    Higher or Lower
    Hangman
    Blackjack
    Tic Tac Toe (work in progress)

Goals

    Learn Python by building projects.
    Improve Linux and terminal skills.
    Practice Git and GitHub.
    Build first, refactor later.
    Keep projects simple and fun.

Future Games

    Dice Poker
    Mastermind
    Minesweeper

Notes

This repository is a learning project. Code may be messy, repetitive, or unfinished while new ideas are being explored.
The focus is on making things work, learning new concepts, and improving over time.
